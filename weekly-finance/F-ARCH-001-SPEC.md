# F-ARCH-001 财务看板新架构 · 纯合成口径与预览（2026-10-23 实现方交付）

所有者直提（2026-10-23）＋ PM 2026-10-23 19:01 细化方案。本文与同目录
`finance-arch.mjs` / `validate-finance-arch.mjs` 只用**纯合成数据**定义口径与
计算契约：不读真实账户、不写生产数据、不改银行账户/调度。生产写回 space-3
的通道仍需所有者另行裁决；裁决前只推进计算与呈现。

## 1. 总资产段：混合日期的最新已知净资产

- 主卡标题口径：「混合日期的最新已知净资产」，不称全账户银行实时。
- 每账户行保留三元组：来源提供的 `asOf`（余额时点）、实现方 `readAt`（读取
  时间）、覆盖标识 `coverage`（`plaid` 按日拉取 / `snapshot` 定期快照沿用）。
- 总卡同时给出两层日期范围（Plaid 层最新 asOf、快照层最旧 asOf）与缺失项
  清单；未知/缺失账户**不当 0**，列入 `missing` 并从总和中排除且明示。
- 负债按既定规则以正额展示、汇总时扣减。

## 2. 花销段：单一 spend 流（取消 fixed/flexible）

- 交易按稳定 ID 去重；`posted` 记入已发生 spend，`pending` 单列不重复计。
- 仅两项定义性排除（所有者已定）：本人账户间转账、贷款还本金。卡还款按
  转账匹配防双计。
- 退款以可追溯冲销行在同一交易流内抵减（保留原支出行与冲销行的配对 ID），
  不静默删除原支出；冲销行归属**原交易月份**，跨月差异在覆盖说明中列明。
- 无法拆分的贷款支付（本金+利息混合且无拆分依据）、未匹配转账：保留在
  `unclassified`，标「分类待确认／覆盖未完整」，不默默剔除、不伪造完整月。
- 当前月标「截至 YYYY-MM-DD」；不生成 fixed/flexible 或任何第三类分类。

## 3. FIRE 口径

- 只消费近 12 个**已结束自然月**中具有完整单一 spend 覆盖的同口径月份；
  缺月明确显示缺哪几个月，不用旧 flexible 口径或更早月份补成 12 个月，
  不年化当前 partial 月。

## 4. F0.6 / F1.6 与 Firance 分工（按 PM 19:01 建议登记，非跨仓决定）

- 旧 fixed/flexible 卡转为「历史对账存档」，不再与日常 spend 并排给两个
  花销答案；旧字段经合成映射表保留来源版本、日期与差异理由，旧数据不
  重算、不删旧行。
- F1.6 月度投资回报保留原资金流/端点覆盖要求；没有同窗依据即「未知」，
  不把日余额差称作收益。
- Firance 本体 `fixed_spend` 结构先作为原样存档来源；Life 日常 spend 按
  本条新口径独立呈现。此为建议边界，不宣称已修改 Firance 或所有者已
  裁决同步方案。

## 5. 异常机制 v0（候选阈值，未定案）

- 基准：近 3 个完整可比月同口径 spend 中位数；当前月优先比较相同经过
  日数的历史区间（月中进度比较与期末整月比较明确区分）。
- 触发候选：相对偏离 > 30% **且** 绝对偏离 > 近月同口径日支出中位数 × 7
  → 列出异常类目与大额笔供下钻。
- 少于 3 个可比月、基准为 0 或 coverage 缺失时不报「显著变动」，只列
  事实/不足。该阈值仅供合成试算与讨论，不据此改真实预算/账户/外发。

## 6. 合成预览（validate-finance-arch.mjs 实跑夹具）

夹具覆盖：高/低/零 spend 月、缺月、退款跨月冲销、重复交易 ID、转账与
贷款本金排除、混合贷款支付未分类、pending 单列、未知账户不当 0、
两层新鲜度日期范围、异常 v0 触发与不触发（样本不足/仅相对超/仅绝对超）。
实跑计数以脚本输出为准，写入 changes.md 本条登记。
